# ADR-0143：普通求助与 Bug 调查共用两轮补充

| 状态 | 决策日期 |
|---|---|
| 已采纳 | 2026-09-11 |

> 当前实施阶段（2026-09-11）：用户决定暂缓 Bug 调查验证，正式入口暂时停止在公开初检之后。需要调查时明确告知未开放并结束；下述调查合同与实现保留，恢复开放另行验证。该阶段限制不增加部署配置，也不影响教学及两轮补充规则。

> 2026-09-14：[ADR-0141](0141-stop-bug-investigation-without-generic-supplements.md) 局部替代调查后的通用补充行为；真实调查返回后结束 Thread，调查前的两轮澄清规则不变。

## 问题

> 2026-09-13：[ADR-0144](0144-resume-bug-investigation-from-public-precheck.md) 局部替代已选插件路径必须先定位具体能力的要求；共享两轮额度和正式入口暂停状态不变。

一次补充后直接关闭，可能把模型的追问和“本次补充已结束”一起发给用户；仅保留首轮和最后一个问题，也无法支撑第二次补充。缺少使用上下文并不等于不能调查，更不能据此确认或排除 Bug。

## 决定

- 整个普通 Support Thread 最多两次补充，首轮不算补充。意图澄清、插件确认、公开初检和 Bug 调查共用额度；更正对象、换题或进入调查不重置额度。
- 程序在追问实际发送成功后预留一次补充机会。模型不计数；发送失败或处理失败沿用失败关闭，不额外增加补充计数。原 scope 隔离、排他 lease、TTL 与重启失效规则保留。
- 保存首轮 request / Reply、已完成的一次补充问答和当前待答问题；最后一次用户补充作为本轮请求传入。保持单条 request、Reply 和问题的边界，合并正文预算容纳这段有限问答，不从尾部丢掉最新补充。不引入摘要模型、长期记忆或新的缓存系统。
- 每轮仍由一次 Low 联合理解意图、观察和插件；结构错误修复机会保持原样。目录未变时，后续输入按时间追加，保留前一轮输入前缀。明确的新任务与对象更正以最新描述为准，当前选择决定提供的插件资料。
- 公开回答生成前收到程序提供的 `can_ask`。有额度只问能够影响下一步且用户可以回答的关键缺项；用户已回答、表示不知道或无法提供的信息不反复索要。程序额外拦截与已发问题完全相同的追问。
- `can_ask=false` 时不允许 `needs_context`，也不能在正文索求信息或要求重发整个问题。普通教学回答已知部分并说明具体限制；异常初检有明确公开用法冲突时解释，否则交给 Bug 入口继续判断调查资格。无额度却输出 `needs_context` 属于无效输出，沿用降级，不为它追加模型修复调用。
- Bug 入口仍必须定位具体能力并有异常观察。满足门槛时携带未知条件继续调查；未定位对象、缺异常观察或调查证据不足时给出相应的无法判断说明，不声称问题已解决、不是 Bug 或已登记。
- Bug Agent 当前只返回结构化结论及缺失证据类别，补充提示由程序生成。提示生成前检查共享额度和已发问题；已经做过初检追问时，不根据宽泛证据类别再次笼统索取全部操作信息。它不重新获得两次提问机会。

## 边界与取舍

两轮是上限，不要求问满。额度用完限制的是向用户追问，调查工具仍服从原有资格、证据和预算；不能绕过调查门槛。普通回复终结后关闭 Thread，后续显式 triage 才是新的求助。Behavior 长期工作区不使用这项补充额度。

本次对内部请求合同增加默认兼容的 `supplements` 和 `can_ask`，现有输出 schema 不变；更新联合判断及公开回答 prompt 修订。更长的补充上下文会增加实际输入量，但没有为轮次管理新增模型调用，不承诺缓存命中或费用下降。

多轮控制、真实消息发送边界和 Bug 调查门槛由回归测试验证。模型是否遵守追问与事实边界仍需要单独评测，控制流测试不构成 held-out 模型资格。

本决定局部替代 [ADR-0060](0060-use-scope-thread-and-post-route-conversation-context.md)、[ADR-0137](0137-interpret-support-supplements-with-the-pending-question.md) 和 [ADR-0138](0138-combine-support-intent-and-plugin-selection.md) 的一次补充与结束提示规则，其余边界继续有效。当前流程见[支持入口与意图路由](../architecture/flows/support-intake-routing.md)。
