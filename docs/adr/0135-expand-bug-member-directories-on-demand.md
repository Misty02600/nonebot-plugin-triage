# ADR-0135：Bug 按教学单元展开成员目录

| 状态 | 决策日期 |
|---|---|
| 已采纳；正式 Bug 入口继续暂停 | 2026-09-13 |

## 问题

真实分页案例首轮输入 58,954 token，第二轮累计 121,333 token，超过 120,000 上限，未能产生最终判断。Agent 已通过源码搜索找到分页实现，却一直携带未使用的完整 meme 成员目录。正文字符预算通过不等于多轮累计 token 预算足够。

## 决定

- 首轮沿用公开事实、初检及对话，成员目录改为教学单元目录，包含本轮 `unit_ref`、owner、名称及成员数量。模型请求的插件信息不再重复列出全部能力 ID；原始 Case 与快照仍保留完整映射。
- 按已有 `(owner, 教学单元 ID)` 分组，没有教学注释的能力各自成单元。不重新归类 family，不用名称子串确定目标；不同插件的同名单元保持独立。
- 增加只读 `read_capability_members(unit_ref)`，从本轮固定映射返回该单元完整的成员入口，随后沿用 `read_capability_evidence(capability_id)` 读取具体事实。公开事实和源码已足够时，无须先展开目录。
- 两种读取与源码等工具共用六次通用额度，返回的证据计入既有正文预算。未知单元返回空结果，未绑定或预算耗尽时隐藏工具。单元展开按完整成员分块，不裁掉成员或绕过总预算；超限仍正常结束。
- 不增加检索模型、向量库、独立预算或公开教学字段。Bug 提示词升至 v13；模型、120,000 累计 token 上限、超时及补充策略不变，正式入口保持暂停。

局部替代 [ADR-0134](0134-share-public-guidance-facts-with-bug-investigation.md) 首轮保留完整成员目录的决定，并调整 [ADR-0133](0133-read-bug-member-evidence-from-the-bound-snapshot.md) 的目录提供时机；公共事实复用、快照和引用边界保持有效。

## 落实与确认

冻结 meme 数据的离线原型将 445 个成员归为现有 10 个教学单元，目录正文从 80,066 降到 836 字符；完整成员归属保留。该测量不含新工具 schema，不能直接当作 token 用量。

相关程序回归 249 项通过，1 项因 Windows 符号链接不可用而跳过。覆盖普通命令、异构参数、正则成员、跨插件同名单元、快照固定、工具共用额度、SDK 工具可见性以及大单元展开超出总预算的正常结束。

原分页案例在相同模型及预算下单次复测：初始正文降至 11,144 字符，首轮输入从 58,954 降至 17,447 token；三次请求、六次工具实际执行，累计总 token 为 69,576，未再超过 120,000。模型最后返回证据不足候选，离线结构及引用检查通过，但包含思考的累计输出为 9,880，超过现有 7,200 输出额度，真实运行仍按分析不可用结束。本次不提高额度或修改模型后重跑，也不据此宣称完整调查通过。

展开非常大的 family 仍会消耗大量上下文；这次只避免每轮调查预先承担全部目录成本，不保证任意规模目录都能在当前预算下完成调查。

后续预算方向由 [ADR-0136](0136-configure-bug-investigation-budgets.md) 部分替代；当前可配置预算与收尾边界的组合以 [ADR-0145](0145-combine-configurable-bug-budgets-with-finalization.md) 为准。

2026-09-15 的后续落实又由 ADR-0136 固定了单次调查的工具定义：成员工具在本轮开始时不可用才不下发，已下发后不再因预算耗尽而隐藏；额度仍由执行层严格检查。上方“耗尽时隐藏”保留为本决定当时的历史实现。
