# ADR-0144：Bug 调查接续公开初检并沿用已选插件范围

| 状态 | 决策日期 |
|---|---|
| 已采纳；隔离验证阶段，正式入口继续暂停 | 2026-09-13 |

## 问题

普通入口已经完成意图与插件选择、完整教学核对和有限补充。旧 Bug Runtime 却只接收 owner 范围和问答，重新检索，再用首条能力记录确定调查对象；初检本轮的输入和结果没有完整交接。搜索虽已按插件合并结果，仍可能在二次匹配时丢掉前序选择，也不能把某条代表记录当作已确定的故障能力。

## 决定

- 已选插件路径传入当前插件集合、对应公开资料快照，以及实际初检输入、执行状态和回答。保留原问题、Reply 与补充问答，不增加摘要模型或要求 Answer 生成额外字段。初检说明仅是可复核的模型分析，不作为可引用的运行证据。
- Runtime 按可信 owner 从当前公开目录复核快照，不重新做词法检索或要求唯一指令。插件缺失、资料变化或目录不可用时按分析不可用结束，不悄悄换对象。无可信选择的旧回退路径单独保留。
- 初检 handled 或等待补充不进入调查。investigate 接续取证；初检失败明确标记未完成，在已有插件范围和异常观察足够时从公开用法核对开始。是否追问及两轮共享额度仍由既有入口控制。
- 一个 Agent 在全部已选插件内调查，共用现有工具与预算。源码路径和 Evidence ID 带本轮插件标识，单文件插件仅允许读取该文件，包插件限于绑定的批准根；不同插件的同名文件不能混淆。插件选择不证明哪个插件有错。
- 调查指纹标识插件集合及资料版本，不伪装成具体能力。首批只验证交接、范围与调查结果，不自动选首条能力登记；恢复正式入口前另外验证结论依据与登记对象，不为本次交接修改数据库。
- 调查提示修订为 v9，说明新输入和插件路径语义。v8 的历史资格保留，v9 不继承；本次不改变判定标准、模型预算和用户追问策略。

## 验证边界

离线程序测试覆盖单插件多能力、多插件、完整与失败初检、补充上下文、资料变化、范围隔离和不自动登记；Pydantic AI FunctionModel 验证实际模型请求携带交接内容。它们不证明真实调查模型能够正确定位原因。正式暂停状态和原有两轮补充规则继续保留。

局部替代 [ADR-0138](0138-combine-support-intent-and-plugin-selection.md) 第 6 项、[ADR-0143](0143-share-two-supplements-across-support-and-bug-assessment.md) 中已选插件路径必须先定位具体能力的要求；旧回退与其他边界不变。
