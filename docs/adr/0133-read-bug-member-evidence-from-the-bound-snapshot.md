# ADR-0133：Bug 调查预装共享教学，按 ID 读取成员事实

首轮独立教学正文及目录关联教学 Evidence ID 的决定已由 [ADR-0134](0134-share-public-guidance-facts-with-bug-investigation.md) 局部替代；按 ID 读取、范围和预算约束仍有效。

完整成员目录的首轮提供时机由 [ADR-0135](0135-expand-bug-member-directories-on-demand.md) 调整为按教学单元展开。

| 状态 | 决策日期 |
|---|---|
| 已采纳；正式 Bug 入口继续暂停 | 2026-09-13 |

## 问题

Bug Runtime 将已选插件的每条成员记录及其教学全部预装。大型 family 重复携带共享教学和大量成员细节，在调用调查模型之前就可能超过证据正文预算。首次预加载又位于协调器异常处理之外，导致该错误无法转为正常结束回复。

仅缩减为 Answer 的教学事实会失去调查可用的成员参数与约束；继续设计通用压缩协议不能保证为后续调查留下足够空间。

## 决定

- 首次提供本轮调查范围的完整公开教学、成员入口目录，以及已有初检和对话。共享教学按内容及所属插件去重，目录将成员 ID 关联到教学证据；目录过长时按完整成员分块，不静默裁掉成员或教学。
- 增加只读工具 `read_capability_evidence(capability_id)`，从本轮已复核快照读取该成员原有公开记录和教学。工具不做模糊匹配，不重新选择插件，不读取全局索引或执行插件。目录外 ID 返回空结果；缺少绑定时不向模型提供该工具。
- 目录中的入口、别名和触发方式只用于发现候选。普通子串命中不等于已确认调用，调查不要求先确定唯一成员。读取不到某项业务限制，不能解释为该限制不存在；索引未收集的动态业务数据仍需其他证据。
- 成员读取计入现有六次通用工具额度，实际返回的证据纳入原有正文预算和引用检查。重复读取仍消耗调用次数，同一证据不重复计入正文。单份详细记录的既有截断与 partial 规则保持有效。
- 首次预加载和 Agent 取证都处于协调器异常处理范围内。资料生成或预算失败按 `analysis_unavailable` 结束，不启动或继续部分资料上的调查，不创建问题记录。
- 不增加检索模型、向量库、family 专属字段或独立预算。提示词升至 v11；历史模型资格不自动继承。正式入口、判定标准和补充轮数不因本次调整改变。

扩展 [ADR-0144](0144-resume-bug-investigation-from-public-precheck.md) 的调查资料提供方式；局部替代 [ADR-0050](0050-use-a-bounded-agent-for-user-bug-assessment.md) 第 7 项的首版工具范围。

## 落实与确认

Runtime 负责公开快照与成员映射，Toolbox 统一计费和登记证据，Pydantic AI 注册原生只读工具。程序测试覆盖不同成员参数、普通命令、正则及别名、范围外和歧义查询、快照固定、目录分块、预算失败与实际 SDK 工具往返。

冻结公开数据的离线测量包含 meme 的 445 个成员、10 个教学单元：初始证据正文由 2,389,039 降至 86,969 字符，全部成员保留；计入证据 JSON 包装为 104,730 字符。这里不包含初检、对话及工具 schema，也不将字符数当作 token 数。

这证明该数据集的输入组装可通过正文预算，不证明真实模型能够正确定位成员或完成 Bug 调查。目前真实多成员 family 数据仍仅来自 meme 的两个 family；其他类型使用程序构造案例验证。

同一冻结数据经真实 Runtime 和检查替身验证，能够完成预加载、进入 Agent 接口、按 ID 读取“表情搜索”的 4,263 字符记录并正常返回证据不足；未调用远端模型。Bug 与相关入口回归分批共 176 项通过，1 项因 Windows 符号链接不可用而跳过。
