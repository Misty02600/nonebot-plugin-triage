# ADR-0138：一次联合判断支持意图与公开插件对象

| 状态 | 决策日期 |
|---|---|
| 已采纳 | 2026-09-10 |

> 2026-09-11：一次补充及补充后结束提示的规则由 [ADR-0143](0143-share-two-supplements-across-support-and-bug-assessment.md) 局部替代；其余决定继续有效。

> 2026-09-13：第 6 项在已选插件路径上要求继续定位唯一能力的规则，由 [ADR-0144](0144-resume-bug-investigation-from-public-precheck.md) 局部替代。

## 问题

独立意图分类与全量目录插件选择读取同一个问题，二者之间没有必须等待新证据的信息依赖。
串行部署两个分类调用增加教学和公开初检的延迟。另一方面，补充使用情况、纠正对象与明确换题
都需要重新理解，直接锁定首轮插件会造成错误续接。

## 决定

1. 用 v8 联合合同扩展现有 Semantic 服务。同一次模型调用输出原有 status、goals、
   reported_observation，以及独立 selection（matched / ambiguous / none、最多五个插件 ID）。
   原有意图含义与确定性路由优先级不变；插件匹配失败不能覆盖意图或自动成为功能反馈。
2. 远端输入允许当前请求、直接相关 Reply、同 scope 首轮请求与实际成功发送的追问，以及全部
   当前可公开、可服务的 catalog。catalog 每个功能包含 name、summary、usages、search_terms、
   behavior_boundaries；内部 owner 映射、平台身份、scope、权限、配置、任意历史与内部证据不外发。
   Reply 是对象和操作上下文，不是独立任务或已验证事实；首轮与补充统一沿用既有 16000 字引用上限，
   请求和追问仍各受 8000 字领域上限约束，新增文本也经过秘密守门。
3. DeepSeek 的联合任务使用 Low，公开回答保留原有模型设置。正常一轮为一次联合判断和一次
   教学回答／公开初检；联合任务只允许一次结构化输出修复，无业务工具，无语义重试；原生 DeepSeek 联合客户端显式关闭 SDK 传输自动重试。
   沿用配置中的整体超时与累计输出限制；默认输出额度从 240 调整为 4096，显式配置保持有效。
   该通用额度也适用于公开回答，不能把它解释为要求回答更长；回答字符合同保持不变。
4. 程序先路由意图，仅教学／Bug 公开初检消费 selection。对象不明确时由程序询问功能或实际指令；
   公开初检缺使用情况时由回答模型提出针对性问题；仅罗列可能原因或重试建议不能结束初检，
   必须有用户信息与公开事实共同支持具体用法冲突才能通过教学结束。它们与意图澄清共用现有一次补充额度，
   发送成功才保存追问；第二轮不再次等待，仍缺信息时必须明确提示重新发送完整问题，明确换题也不重置额度。
   对象仍不明确时保留已经明确的原意图；仅回答部分追问时，未回答的关键条件仍为未知。
5. 程序验证插件引用，重新校验当前资料和可见性，再按所选插件装配完整教学及适用调用规则。
   不强制定位子命令，不以 catalog 未列出某写法判为非法。教学继续按整插件装入预算，
   首个插件放不下时明确不可用，后续插件被省略时保留材料受限标记，不静默截断。
6. Bug 调查接收模型外解析的 owner 范围，既有对象解析在该范围内继续；它仍须确认具体能力、
   检查公开合同与实际观察、收集证据，不能把插件选择或虚构检索分数当成 Matcher 证据。
   没有可信目录时保留原有显式公开 Alconna 回退及 Bug 准入路径，不把目录失败说成不支持。
7. catalog 使用稳定顺序和目录内短编号；目录刷新后必须校验所选编号仍指向原 owner。资料未变时补充请求完整保留首轮联合输入前缀，
   追加追问和当前答复；公开回答把稳定事实放在动态问题之前。每轮重新读取当前资料，
   不新增通用缓存系统，不依赖缓存保证正确性，也不承诺命中率。新任务不继承旧目标和观察。
8. 模型执行失败、资料不可用、对象不明和明确未匹配分开处理。模型失败直接说明暂不可用，
   不再使用“用户没有讲清楚”的追问。权限、实际平台操作和故障记录仍由原有模型外流程控制。

## 取舍与验证

合并减少常见路径的一次串行请求，但范围外、反馈和内部行为请求也会携带 catalog，不能仅凭调用数
断言总费用下降。Low 联合判断和补充轮缓存必须独立验证，原 v7 语义资格或独立选择器实验不能继承。
当前质量标签按新任务、schema、Prompt、输入策略和设置修订保持未验证；开发样本通过不等于 held-out 资格。

本次不增加检索工具、“是否重新选择”的模型、独立摘要任务、多轮补充系统或新的意图枚举。

局部替代 [ADR-0038](0038-limit-semantic-assessment-remote-data-projection.md)、
[ADR-0060](0060-use-scope-thread-and-post-route-conversation-context.md)、
[ADR-0137](0137-interpret-support-supplements-with-the-pending-question.md) 的输入范围限制及 v7 合同，
并替代 [ADR-0037](0037-make-semantic-assessment-the-default-triage-path.md) 中旧单请求预算的适用部分。
显式入口、同 scope 一次补充、模型外鉴权和证据判定继续有效。
