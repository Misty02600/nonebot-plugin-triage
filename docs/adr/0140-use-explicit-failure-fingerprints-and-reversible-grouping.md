# ADR-0140：使用显式故障指纹并允许纠正自动聚合

| 状态 | 决策日期 |
|---|---|
| 已采纳；用户认可判断、聚合和纠正边界后实施 | 2026-09-13 |

## 问题

关联日志的 `revision` 在不同采集器中分别表示日志签名或内容摘要，旧聚合器却把所有 64 位摘要当作故障身份。
同一搜图死锁的两次独立调查还因一次定位到插件、一次定位到指令而被拆成两个 Problem。
宽泛失败字段、统一错误回复或相同异常类型都不足以区分缺陷；自动分组也不能保证根因相同。

## 决定

- 保留三值判断和现有责任字段，不增加分类模型或模型必填字段。统一失败回复、单次超时、内存耗尽、
  重试成功以及发生频率都不能单独确认或排除缺陷。外部故障可能触发内部错误处理缺陷。
  充分证据证明合法操作得到错误结果时，不要求异常栈或准确根因。教学与代码冲突时核实资料适用性；
  不能确认哪一边有误则 unknown，不能把仅确认的教学资料错误登记成目标插件实现 Bug。
- 只有通过 reconciler 的 Bug 进入既有 Report / Occurrence / Problem / Decision 库。
  未知和非 Bug 不新建问题；无法生成指纹的 Bug 仍独立保存。
- 采集器显式提供 `FailureFingerprint(kind, algorithm_revision, digest)`，Evidence revision 只记录证据版本。
  不从模型输出、日志普通正文、内容哈希或宽泛运行失败字段推断分组身份。
- 首版支持完整异常链与完整应用等待路径，也接受受控采集器提供的专用指纹。
  真实异常读取模块、函数、调用点、异常链和详情；两类路径共用应用帧筛选和规范化。
  去掉框架调度帧，帧身份不使用安装路径和绝对行号；仅规范化明确标记的请求标识和 ISO 时间，保留错误码与业务值。
  缺少应用调用点、截断现场、未知来源或异常组暂不自动聚合。
- Problem 指纹 v2 包含排序后的受影响插件集合、适配器和采集器指纹。具体 capability 仅作关联信息。
  只使用最终引用的当前完整运行或日志证据；有多个不同故障身份时不猜测主次。
  不跨插件集合自动推断共同根因，也不把同一故障时间窗口等同于同一软件缺陷。
- 不把源码、资料或部署版本作为故障身份；各次调查仍独立保留版本与证据，匹配不短路调查或套用旧 verdict。
  新算法不重写旧 Problem；旧枚举保留历史可读性，但不再从宽泛字段生成那些签名。
- 提供维护者拆分操作：原子迁移某次 occurrence、其全部报告及可准确关联的 Agent 调查到独立 Problem。
  调查内容、证据引用和 `previous_decision_id` 不改；后者继续表示调查当时的依据，可以跨拆分后的问题引用。
  原问题人工判断不复制，新问题待复核，不猜测新责任方。
- 拆分审计保留来源、目的问题、发生标识、报告/调查 ID、操作者摘要和幂等键。
  原 Problem 保留指纹作为停用记录；后续命中该指纹独立建档，避免重新合回。
  调查与发生关联不完整的旧记录拒绝猜测拆分，不自动回填历史关联。

## 实施与限制

`triage 报错查询 <P-编号> 发生记录` 查看最近至多 100 条发生及摘要；
`triage 报错查询 <P-编号> 拆分 <发生标识>` 执行纠正。继续使用维护者鉴权，不调用模型。

迁移 `a91bd7240e56` 添加指纹停用状态、调查的 occurrence 关联及拆分审计表。
未执行拆分时支持回退；存在拆分审计时拒绝删除停用约束的降级。部署升级由维护者执行，不自动升级宿主数据库。

生产异常观察器提供异常指纹；搜图复现的完整等待现场由复现适配器提供，不冒充已实现通用生产卡死采集器。
没有日志和现场时允许 unknown；不建设通用内存诊断、跨插件事件关联、向量聚类、自动根因合并或批量重组系统。
语义边界通过 Prompt v19 约束，程序引用校验不能替代因果判断。正式 Bug 入口继续暂停。

## 落实与确认

- 异常身份、完整等待路径、插件/适配器范围、正文哈希不聚合、多个故障不猜测、安装路径与行号变化由针对性测试覆盖。
- 两次已保存的独立搜图调查重放通过：模型输出不变，仅由已校验捕获补充新采集器元数据，在隔离 SQLite 中关联同一 Problem。
- 拆分测试覆盖关联迁移、调查内容保留、人工复核不复制、投影更新、幂等、后续不重新合并、旧数据拒绝和事务回滚；迁移与维护者命令另有测试。
- [七条合成开发样本](../../evals/datasets/fixtures/bug-assessment-v18-boundaries-development.json) 使用真实 DeepSeek V4 Flash / High 验证，v18、v19 的三值判断均为 6/7。
  “超时后重试成功但缺少归因证据”仍误判 not_bug：v18 归为用户前置条件，v19 改为临时外部故障。该题保留为未通过；未声称获得发布资格，不继续针对它追加规则。
