# ADR-0134：Bug 调查沿用 Answer 的公开事实

首轮保留完整成员目录的决定已由 [ADR-0135](0135-expand-bug-member-directories-on-demand.md) 局部替代；公共事实复用及引用规则仍有效。

| 状态 | 决策日期 |
|---|---|
| 已采纳；正式 Bug 入口继续暂停 | 2026-09-13 |

## 问题

初检交接已经包含实际请求中的公开事实。Bug 再预装独立转换的教学正文，既重复输入，又维护了两种教学投影。调查需要更多证据，但不需要重新组织同一份公共知识。

## 决定

- 初检请求存在时，沿用其 `facts`、原编号、内容和 basis；程序将每条事实映射为 `public-guidance:fN` 证据，计入现有正文预算和引用检查。候选资料遗漏状态独立保留，不能推断缺失规则不存在，也不把已提供的完整事实标为截断。
- 发送给 Bug 模型的事实正文只出现在预加载证据中。`public_guidance` 提供编号映射和遗漏标记，初检请求中的 `facts_ref` 指向该组事实。原始初检请求与回答在本地对象中保留；初检回答仍是可复核的分析，不登记为证据。事实未预加载或绑定内容不一致时，模型调用前停止。
- 没有初检事实时，从已复核公开快照调用 Answer 的 `build_public_guidance_request` 组装资料，不增加模型调用。补建资料不写回实际初检历史；失败状态不伪装成已完成。无法组装时按分析不可用结束。
- 删除 Bug 首轮独立教学正文，保留完整成员目录及按 ID 读取工具。目录仅关联所属 `analysis_unit_id`，不再引用已删除的教学证据。具体记录和原始教学仍能按需读取，范围、预算及失败处理沿用现有约束。
- 不调整 Answer 的提示词、事实结构、资料投影和回答策略；不新增通用上下文框架。Bug 提示词升至 v12，不继承历史资格。目录成本及真实模型调查质量仍需后续验证。

局部替代 [ADR-0133](0133-read-bug-member-evidence-from-the-bound-snapshot.md) 首轮独立预装共享教学及目录关联教学 Evidence ID 的决定；按 ID 读取、快照和预算约束保持有效。

## 落实与确认

程序测试覆盖事实单次发送、引用对应、遗漏状态、失败初检、无事实时复用同一组装函数、不伪造历史、资料生成失败与 SDK 请求绑定检查。Bug、相关入口与 Answer 回归共 245 项通过，1 项因 Windows 符号链接不可用而跳过。测试采用程序替身和 Pydantic AI FunctionModel，不代表真实调查模型通过评测。

冻结 meme 资料的两条 Runtime 隔离路径均保留 445 个成员、82 条 Answer 事实，未重复预装原始教学，成员读取成功。初始证据正文为 89,957 字符，较前版 86,969 增加 2,988 字符；没有初检记录的序列化 payload 为 139,479 字符，带本次构造的失败初检记录为 139,635 字符。事实逐条提供引用包装，因此本次统一结构不等于压缩整个请求。这些数值不包含工具 schema，不是 token 用量，也不能推算真实模型的调查成功率。
